HTML5, CSS3, JavaScript 간단 학습

웹 페이지를 구성하는 기본 개념을 이해하고, 직접 예제를 만들어보며 공부해보세요.

웹 개발의 3대 요소

HTML은 구조를 만들고, CSS는 디자인을 꾸미며, JavaScript는 상호작용을 넣는 역할을 합니다. 이 페이지는 각 요소의 핵심 개념을 한눈에 볼 수 있도록 구성했습니다.

# HTML5 # CSS3 # JavaScript
<h1>Hello, World!</h1> <button>클릭</button>

1. HTML5

HTML이 하는 일

HTML은 웹 페이지의 내용을 구조화하는 언어입니다. 제목, 문단, 이미지, 링크, 버튼 등을 표현합니다.

주요 요소

  • h1 ~ h6: 제목
  • p: 문단
  • button: 버튼
  • a: 링크

예시

웹 문서의 의미를 갖는 태그를 사용하면 브라우저와 검색 엔진이 내용을 더 잘 이해할 수 있습니다.

2. CSS3

CSS가 하는 일

CSS는 색상, 크기, 간격, 레이아웃, 애니메이션 등을 설정해 웹 페이지를 꾸며줍니다.

핵심 개념

  • 선택자: 어떤 요소를 꾸밀지 선택
  • 속성: color, background, margin 등
  • 레이아웃: flex, grid

예시

버튼에 색상, 둥근 모서리, 그림자 효과를 추가하면 더 보기 좋은 UI를 만들 수 있습니다.

3. JavaScript

JavaScript가 하는 일

JavaScript는 사용자와 상호작용하는 동작을 담당합니다. 클릭, 입력, 계산, 애니메이션 등을 구현합니다.

기본 문법

  • 변수: let, const
  • 함수: 코드 재사용
  • 이벤트: click, input 등

실전 팁

DOM을 다루며 button을 눌렀을 때 텍스트를 바꾸거나 값을 계산하는 방식으로 프로그램을 만들 수 있습니다.
